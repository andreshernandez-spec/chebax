# External review 2026-07-30: findings and disposition

A read-only external review of HEAD `8cbd54f` found 26 numbered issues,
several release-blocking. Every reported reproduction was confirmed before
fixing. This file tracks disposition; the fix details live in the commit
messages and the code comments at each site.

## Fixed

| # | Finding | Fix |
|---|---|---|
| 1 | Adaptive `fit` certified aliased fits (T_34 -> constant -1) and mishandled DCT noise (sin(20x) -> degree 230, sin(50x) -> failure) | Two-part criterion in `generate.py`: noise-aware chop (level from the trailing coefficients, accepted only at the requested tol or at a measured plateau that node-doubling no longer improves) plus mandatory off-grid validation, which aliasing cannot pass |
| 2 | Inverse solvers returned wrong deep-tail quantiles silently (betaincinv(1,1,1e-50) -> 4.8e-29; gammaincinv(20,1e-20) -> 1.53 for 0.865) | Exact leading-asymptotic initializers, mandatory post-solve CDF-residual check (nan on failure), underflowed quantiles return 0.0 |
