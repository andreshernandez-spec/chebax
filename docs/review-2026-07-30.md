# External review 2026-07-30: findings and disposition

A read-only external review of HEAD `8cbd54f` found 26 numbered issues,
several release-blocking. Every reported reproduction was confirmed before
fixing. This file tracks disposition; the fix details live in the commit
messages and the code comments at each site.
